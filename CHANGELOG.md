# Changelog

## 0.1.0 — Development preview (2026-11-02)

- Implemented Python CLI, input validation, project initialization and GTF/GFF3 tx2gene conversion.
- Added three bulk RNA-seq routes: counts, Salmon quant.sf, FASTQ via fastp and Salmon.
- Added FastQC, MultiQC, DESeq2 results, sample QC figures, GMT ORA / fgsea, optional WGCNA, and HTML report index.
- Added synthetic test inputs, input-boundary tests and GitHub Actions for Python tests.
- Explicitly documented unsupported methods and required independent R/tool validation.
