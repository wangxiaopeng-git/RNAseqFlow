# Methods, assumptions, statistical reporting

## Input provenance

- A raw count represents a fragment assigned to a gene, typically generated by featureCounts, HTSeq, or comparable methods. For paired-end data, counting settings must match fragment vs read treatment.
- Salmon `NumReads` is an estimated count; `tximport` combines estimates and transcript lengths into gene-level count models through `DESeqDataSetFromTximport`. Transcripts must map to their correct genes from exactly the same annotation.
- FPKM/TPM/CPM values cannot be substituted for unnormalized count data in `DESeqDataSetFromMatrix`. TPM is exported as a descriptive abundance matrix only.
- A raw genomic reference alone is insufficient for the v0.1 Salmon mode: provide a matching **transcriptome FASTA**. A decoy-aware transcriptome is preferable for difficult references and related paralogs.

## Filtering, statistical model, and contrasts

- Genes are retained when count >= `min_count` in >= `min_samples` samples. These defaults are conveniences; change them according to library sizes and group sizes.
- Size factors use the DESeq2 median-of-ratios estimator. Residual degrees of freedom and full rank of the design matrix are verified before fitting.
- The default Wald test evaluates each specified contrast as zero differential expression using a negative-binomial model, with BH FDR control among tests returned by DESeq2.
- `|log2FoldChange| >= log2fc` is a post hoc table-selection threshold. For a formal minimum-effect test, an explicit DESeq2 `lfcThreshold` / `altHypothesis` setup is needed and not currently exposed.
- Sample PCA uses transformed gene expression for intermediate/advanced; basic uses log2(normalized counts + 1). A PCA cluster does not demonstrate batch removal or statistical independence.
- Gene heatmaps scale each gene to a within-gene Z-score for pattern display; it is invalid to infer fold changes from the color scale alone.

## Functional enrichment

- All eligible GMT gene sets are tested with a hypergeometric ORA. Background is the intersection of gene sets and retained, tested genes (with within-pathway members intersected with the retained set). BH correction is across all eligible pathways, not only those with overlap.
- Preranked GSEA uses DESeq2 Wald statistics and `fgseaMultilevel`, with `min_set_size`/`max_set_size` configured. Rank sizes and ties may affect interpretation; check warnings and contrast direction.
- No online GO/KEGG web server is involved. The code does not infer KO, GO, or KEGG assignments from gene symbols. Provide a documented GMT based on direct orthology/functional annotation evidence, not the demo `TOY_` sets.
- Network module traits are observational associations; padj is corrected within the set of module–trait hypotheses in each analysis, not across multiple projects.

## Design validity and reproducibility

- For two-group experiments, at least three independent biological replicates per group are normally advisable; the validator only rejects fewer than two, allowing software demonstration and marginal data diagnostics. Unbalanced confounding and batch effects must be inspected.
- Avoid treating technical replicates as independent biological replicates. Do not model a confounded batch and condition as jointly estimable if no independent contrasts exist.
- WGCNA uses transformed expression and selected most variable genes. At least 20 samples is only a pragmatic minimum; network robustness should be investigated with larger datasets, alternative powers and bootstrap stability checks.
- R sessionInfo and YAML configuration accompany each run; real analysis should additionally archive reference FASTA/GTF versions, sample IDs, experimental design, technical replicates, software hashes, parameter changes and data accessions.
- Synthetic examples contain injected effects solely to verify program structure. No biological interpretation is supported by this data.

## Testing gaps to close before v1.0

1. Execute the `counts` mode with a real R/Bioconductor installation and compare against standalone DESeq2 analyses.
2. Execute `salmon` mode on known quant.sf references and compare `tximport` count matrices and DESeq2 estimates.
3. Execute both single-end and paired-end FASTQ workflows with a verified transcriptome and confirm MultiQC/Salmon artifacts.
4. Compare ORA with a reference implementation and inspect GSEA convergence warnings and gene-set coverage.
5. Stress-test WGCNA for correlated genes, zero variance, batch effects, small n, and high-dimensional matrices.
6. Test Linux/macOS portability; large-file storage and HPC resource observability.
